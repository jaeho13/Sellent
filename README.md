## 🚀 프로젝트 이름
### Sellent(재능 판매 사이트)
<br />

## 🚀 프로젝트 개요
### 개인의 흔한 재능이 타인에게는 필요한 재능일 수 있기에, 재능을 공유하며 구매 및 판매하는 웹사이트
<br />

## 🚀 프로젝트 기간
### 23년 9월 ~ 23년 11월
<br />

## 🚀 프로젝트 목적
### Front-end
#### React, Spring 연동 CRUD 구현
#### 네이버 및 카카오 로그인 API 구현
#### 카카오 지도 및 카카오 결제 API 구현
<br />

## 🚀 프로젝트 기능
### 재능 판매를 위한 게시물 작성
### 거래 장소를 정하기 위한 주소 작성 시 지도 생성 
### 재능 거래를 위한 카카오 결제
### 마이페이지에서 거래한 재능 보기
<br />

## 🚀 프로젝트 초안 
### 1. 프로젝트 실행 시 비 로그인 상태에서도 게시물을 볼 수 있습니다.
### 2. 로그인 성공 시 글을 작성할 수 있습니다.
### 3. 로그인 성공 시 마이페이지에 들어가서 구매 혹은 판매 재능을 볼 수 있습니다.
<br />

## 🚀 느낀점
### 결제와 지도 등 기존에 사용하지 않았던 API를 프로젝트에 도입했으며, 그 외에도 검색과 파일 업로드 등 다양한 기능을 추가로 구현해 보았다.
### 프로젝트를 진행하는 동안 결제 프로세스 기획 및 구현 과정에서 어려움을 겪었는데, 결제 전후 처리 과정과 검증 등 여러 단계를 관리하는 것이 까다로웠지만 사용자 유즈케이스 분석을 통해 문제를 해결하였다.
### 추가적으로 사용자를 고려한 설계의 중요성을 알게 되었다.
